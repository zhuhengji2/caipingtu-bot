# 彩平图机器人 · caipingtu-bot

把 CAD 黑白户型线稿，批量渲染成**室内设计彩平图（colored floor plan）**，并自动擦除生图平台强制加的水印。

为室内设计师做的实用工具集：一套经过实战校准的**提示词模板** + 三条**风格基线**（现代奶油 / 宋式美学 / 中古风）+ 一个**LaMa 深度学习去水印**脚本。

> 核心原则：**户型结构保真 > 一切风格表现**。彩平图可以换风格，但不能变形。

---

## 这个仓库解决什么问题

| 痛点 | 做法 |
|---|---|
| AI 生成的彩平图布局乱跑、墙变斜、房间被重排 | 结构逐条写死的提示词模板（见 `docs/prompt-template.md`） |
| 每次风格不统一，成套方案对不上 | 三条风格基线 + 固定基准图 + 量化配色规格（见 `docs/style-baselines.md`） |
| 出图带平台水印，交付前还得手动修 | LaMa 深度修复自动擦除，非裁剪、不留涂抹痕（`lama_remove.py`） |
| 图太平，没有灯光氛围 | 灯光表现块，已成为所有风格的必带项 |

## 工作流

```
CAD 线稿(.png)  ──┐
                  ├─►  生图模型（双图输入：线稿 + 风格基准图）
风格基准图(.jpg) ──┘            │
                                ▼
                        彩平图（带平台水印）
                                │
                                ▼
                   lama_remove.py（LaMa 修复擦水印）
                                │
                                ▼
                        干净成品 · 可直接进方案册
```

**说明**：图像生成本身依赖生图模型（WorkBuddy / 即梦 / Midjourney 等），不在本仓库内。本仓库提供的是**提示词 + 风格规范 + 后处理**这三块真正决定成片质量和一致性的部分。

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

依赖：`onnxruntime`、`opencv-python-headless`、`numpy`（纯 CPU，无需显卡）

### 2. 下载 LaMa 模型（208 MB，仅首次）

```bash
python download_model.py
```

脚本会以 8 线程断点续传下载到 `models/lama_fp32.onnx`，网络不稳也能续传（国内走 hf-mirror 镜像）。

### 3. 擦除水印

```bash
# 单张
python lama_remove.py detect output/plan.png

# 整个文件夹（.png / .jpg）
python lama_remove.py detect output/

# 整个右下角区域重建（用于修复传统算法留下的涂抹痕迹）
python lama_remove.py rect output/plan.png
```

`detect` 用背景差分定位文字掩膜，`rect` 直接重建右下角矩形。两者都用 LaMa 模型修复，会重建木纹、墙面、家具纹理，而不是简单涂抹。

## 出图四步法

1. **读图**：把线稿的房间结构逐条写成文字（从左到右、从上到下，"客厅 L 形沙发+圆几、餐区六椅、厨房 L 形橱柜……"）。
2. **拼提示词**：用 `docs/prompt-template.md` 的骨架填三段——结构块 + 风格块 + 灯光块。第一条永远是"几何保真第一优先"。
3. **生成**：线稿作 image1、风格基准图作 image2，`input_fidelity=high`，**尺寸与线稿一致**（横版 1536×1024 / 竖版 1024×1536）。
4. **验收**：对照线稿逐项核对功能区数量和位置，不通过就改提示词重出（不要凑合，错的结构修不了）。

## 关键经验（踩过的坑）

| 坑 | 原因 | 解法 |
|---|---|---|
| 布局被参考图带跑（L 形弧墙） | 输出尺寸和竖版参考图一致，模型连户型一起学了 | 尺寸跟线稿，并在提示词里写明"参考图仅作风格参考，严禁照搬户型" |
| 墙体填充色被带偏（灰变棕） | 只说"参照参考图"太笼统 | 逐项写死颜色：墙体中灰、地面奶油米白、背景只在户型外围 |
| 修复区出现灰色糊块 | OpenCV `inpaint` 遇到深色墙体就平均化 | 换 LaMa 深度修复模型（本仓库方案） |
| 水面/地板纹理被水印遮挡后糊成一片 | 同上 | `rect` 模式整块重建 |
| 中文字路径读取失败 | `cv2.imread` 不支持非 ASCII 路径 | 脚本内已用 `np.fromfile` + `imdecode` 处理 |

## 目录结构

```
caipingtu-bot/
├── lama_remove.py            # LaMa 去水印（detect / rect 两种模式）
├── download_model.py         # 208MB 模型断点续传下载器
├── requirements.txt
├── docs/
│   ├── prompt-template.md    # 提示词模板（结构块/风格块/灯光块）
│   └── style-baselines.md    # 三条风格基线的配色材质规格
├── reference/                # 放你自己的风格基准图（不入库）
├── samples/                  # 放你的成果图（不入库）
└── models/                   # 模型权重（不入库，脚本自动下载）
```

`reference/` 和 `samples/` 默认被 `.gitignore` 排除——**客户项目的线稿和成品图不要推到公开仓库**。

## 三条风格基线速查

| 风格 | 墙体 | 地面 | 家具 | 氛围 |
|---|---|---|---|---|
| 现代奶油 | 深炭灰剖面 + 暖橙灯带 | 浅原木地板 | 米白布艺、浅木 | 暖奶油、干净 |
| 宋式美学 | 中灰剖面 | 奶油米白 + 浅灰地毯 | 奶油白布艺、原木、朱砂红圆凳 | 低饱和古画、外围绢本山水底 |
| 中古风 | 砖红/橘红剖面 | 客餐厅深藏青、厨卧木地板 | 奶油白沙发、彩色餐椅、宝蓝圆毯 | 浅粉底、扁平插画风 |

详细配色与材质见 [`docs/style-baselines.md`](docs/style-baselines.md)。

## 已知限制

- AI 生成是**高保真还原**，不是像素级精确。墙厚、门洞位置偶有小出入，交付前必须人工核一遍。
- 复杂户型（异形、多折线）建议先拆分区域分别出图。
- 生图模型由平台提供，单张有额度成本；去水印是纯本地计算，免费无限次。
