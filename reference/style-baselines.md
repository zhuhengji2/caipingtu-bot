# 风格基线规格

三条已定稿的风格基线。每条都需要一张**固定基准图**（放在 `reference/`）作为双图输入的第二张图——基准图一换，整套方案的视觉语言就变了，所以按风格固定下来，不要临时换。

## 通用规则（所有风格）

1. **结构保真优先于风格表现**：宁可风格淡一点，也不能让户型变形
2. **输出尺寸跟线稿**：横版 1536×1024，竖版 1024×1536
3. **参考图只管风格**：提示词必须写"严禁照搬参考图户型布局"
4. **必须带灯光**：顶灯光斑、灯具发光、柜下灯带、家具投影
5. **无文字**：不要尺寸标注、房间名、logo

## 一、现代奶油（默认风格）

| 部位 | 规格 |
|---|---|
| 墙体 | 深炭灰填充剖面，边缘带暖橙灯带光晕 |
| 地面 | 浅原木色木地板；厨卫浅色瓷砖 |
| 家具 | 米白/奶油布艺，浅木色，白色大理石台面 |
| 基调 | 暖奶油、低饱和、干净，真实感 3D 俯视渲染 |
| 适合 | 现代住宅、刚需与改善型、面向大众客户的方案册 |

## 二、宋式美学

| 部位 | 规格 |
|---|---|
| 墙体 | **中灰色**实体剖切（不要棕褐、不要深色） |
| 地面 | 奶油米白/暖白，客厅浅灰地毯，厨卫浅灰瓷砖 |
| 家具 | 奶油白布艺、原木色家具、朱砂红圆凳、琥珀色小面积点缀 |
| 背景 | 茶色绢本宋画山水（淡彩山峦、松树），**只在户型外围**，内部保持米白 |
| 基调 | 低饱和古画色、雅致克制，真实感 3D 俯视渲染 |
| 适合 | 文化调性业主、东方风格提案、概念方案 |

## 三、中古风

| 部位 | 规格 |
|---|---|
| 墙体 | 砖红/橘红色实体剖切 |
| 地面 | 客厅餐区深藏青/炭黑；厨房卧室中棕木地板 |
| 地毯 | 客厅圆形宝蓝地毯 + 橙色圆心 |
| 家具 | 奶油白沙发床品、红黄蓝绿彩色餐椅、芥末黄/橄榄绿点缀、绿植 |
| 背景 | 浅粉/米粉净底 |
| 基调 | 扁平 2.5D 插画风，色块干净无渐变，无人物无箭头 |
| 适合 | 年轻业主、内容平台展示、社媒传播（视觉冲击强） |

## 基准图管理

```
reference/
├── modern-cream.jpg     # 现代奶油
├── song-style.jpg       # 宋式美学
└── mid-century.jpg      # 中古风
```

**换风格 = 换基准图，不是改提示词。** 想把某张小红书/站酷上看到的彩平图变成自己的风格，做法是：截图存进 `reference/`，按它的实际配色重写风格块里的颜色描述，然后固定下来。

注意：**别人的作品只能作为风格参考，不要直接二次分发**。同时确保基准图里不含他人水印或 logo，提示词里也要写明"不要出现参考图中的 logo 文字"。
