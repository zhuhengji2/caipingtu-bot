# 提示词模板

三段式：**结构块 + 风格块 + 灯光块**。结构块永远排第一，因为模型对先出现的要求权重更高。

---

## 骨架（直接复制改写）

```
将第一张图（CAD黑白线稿户型平面图）渲染为{风格名}、带灯光表现的室内彩平图。
重要：第二张图仅作{色调/材质/配色}参考，严禁照搬其户型布局；户型唯一依据是第一张线稿。

【户型结构 —— 必须逐项一致】
{户型描述：从线稿按"上排从左到右 / 下排从左到右 / 边缘"顺序写清每个功能区 + 主要家具}
墙体全部横平竖直正交，不得斜墙弧墙，不得旋转镜像重排，家具只在原位置上色不挪动。

【填充颜色】
{风格块，见下}

【灯光表现】
{灯光块，见下}

俯视90度正视角，{渲染质感}渲染，无任何文字标注、无尺寸线、无logo。
```

---

## 结构块怎么写

不要写"按原图布局"——模型会自由发挥。要**逐项点名**：

```
横版矩形户型，上排为公共区、下排为私密区。
上排从左到右：客厅（L形转角沙发+圆形茶几+电视柜）、餐区（长餐桌+六把餐椅）、
              厨房（L形橱柜：灶台+水槽+冰箱位）、过道、卫生间（双台盆+浴缸+马桶）；
下排从左到右：四间卧室（各带床和衣柜，第一间另有书桌+圆椅，最右一间双人床带两侧床头柜）；
底部边缘三个阳台（藤椅+小圆桌）。
```

要点：
- 用"从左到右 / 自上而下"的空间顺序，模型对序数关系敏感
- 数量必须写死（**四间**卧室、**六把**餐椅、**三个**阳台）
- 特殊件单独点名（书桌、浴缸、双侧床头柜），否则会被省略

## 风格块

### 现代奶油

```
深炭灰色墙体填充剖面，墙体边缘带暖橙色灯带光晕；浅原木色木地板；米白色布艺沙发和床品；
浅木色家具；白色大理石台面；暖奶油色调，干净简洁。
```

### 宋式美学

```
墙体中灰色实体剖切（不要棕褐色、不要深色）；室内地面奶油米白，客厅铺浅灰地毯，厨卫浅灰瓷砖；
家具宋式简雅：奶油白布艺、原木色家具、朱砂红坐垫圆凳与琥珀色小点缀（点缀面积要小）；
茶色绢本宋画山水底只出现在户型外围（淡彩水墨山峦与松树），户型内部保持米白干净。
```

### 中古风

```
墙体砖红/橘红色实体剖切；客厅餐区地面深藏青/炭黑，厨房卧室中棕木地板；
客厅铺圆形宝蓝地毯配橙色圆心；家具中古彩色系：奶油白沙发床品、红黄蓝绿彩色餐椅、
芥末黄橄榄绿点缀、绿植盆栽；背景浅粉净底，扁平插画质感。
```

## 灯光块（所有风格必带）

```
每个房间有清晰的灯光光效：餐桌/客厅吊灯在桌面和地面形成暖黄色圆形光斑，
客厅落地灯/球形台灯发出暖光晕照亮沙发地毯，各卧室床头灯形成柔和暖光，
厨房橱柜台面有暖色灯带洗墙，卫生间洗面盆上方暖光；
灯具本体高亮发光，家具投下柔和阴影，有明暗对比和光斑过渡，氛围温馨但不邋曝。
```

深色地面的风格（如中古风）把"光斑对比明显"再强调一次，效果最好。

## 参数建议

| 参数 | 建议值 | 说明 |
|---|---|---|
| 输入图 | 线稿 + 风格基准图（两张） | 双图输入是风格统一的关键 |
| `input_fidelity` | `high` | 低档位会丢线稿细节 |
| 尺寸 | 横版线稿 1536×1024 / 竖版 1024×1536 | **必须跟线稿一致**，否则布局会被参考图带跑 |
| quality | `high` | 彩平图要给客户看，别省 |

---

## 验收清单（每次都过一遍）

- [ ] 功能区数量和位置与线稿一致（尤其卧室间数、卫生间个数）
- [ ] 墙体全部正交，无斜墙、弧墙、曲线
- [ ] 家具在原位置，没被挪动或增删
- [ ] 填充颜色符合风格块（墙体颜色最容易跑偏）
- [ ] 有灯光光斑和阴影，不是平光
- [ ] 无文字、尺寸线、logo、水印
